# presentation-design

Välj layout efter budskap, inte efter tillgängliga figurer. Använd före–efter, utvecklingsresa, lager, förmågekarta, informationsflöde eller fri konceptillustration. För ledning: en huvudpoäng per sida, rubrik som förmedlar slutsatsen, minimera teknisk detalj. Föreslå alternativa kompositioner när det hjälper; skapa inte tre varianter slentrianmässigt.

Vid rekonstruktion från referensbild: följ reconstruction-guide.md, använd redigerbara konturikoner och fria vektorformer, rendera och jämför med originalet.
