# Visualiseringsbibliotek
Välj mönster efter budskap, inte efter notation. Använd patterns.yaml som katalog. Alternativen är inte låsta koordinatmallar. Välj jämförelse för likvärdiga alternativ, destination för målbildens nytta, resa för jämförbara generationer, steg för kvalitativ utveckling (inte mätvärden), lager för nivåer och fundament för möjliggörande tjänster. Karta visar bredd, nav visar samhörighet utan att påstå tekniska beroenden. Flöde visar riktning; förgrening visar återanvändning. Pilar får inte antyda ogrundade samband. Begränsa etiketter och använd rubriker som uttrycker slutsatsen. Återanvänd figurer med temats färgroller. Ändra komposition om innehållet inte ryms; krymp inte text godtyckligt. Exempelgeneratorn är ett utvecklingsverktyg, inte en runtime-motor.
